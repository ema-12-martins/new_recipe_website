# Quick 261023-h1n: Apply sketch 001 winner A (kraft paper) to the website

## Objective
Give the live cookbook the warm "Papel kraft" look the user chose in
`.planning/sketches/001-rustic-list-and-recipe/` (winner A), without changing behaviour,
data, routes or copy.

## Scope decisions
- Visual only. Sketch-only ideas (ticking ingredients, current-step highlight, search,
  list|recipe split view, ingredient/step counts on the list) are NOT built: the list query
  returns only id + title, and split view would change routing.
- Dark mode keeps following the system setting (existing behaviour, Phase 2 UI-SPEC): add a
  dark "espresso kraft" token set instead of dropping dark mode.
- Every colour stays a theme token (shadcn CSS variables), so other pages (sign-in, setup,
  join, members, new/edit, capture) inherit the palette and fonts automatically.
- Fonts are self-hosted with `next/font/google` (downloaded at build, served from
  `/_next/static/`, already cached by the service worker for offline use).
- Recipe text is still rendered as plain text exactly as stored (D-11): keep
  `whitespace-pre-wrap` and `break-words`.

## Tasks

### Task 1: Kraft theme tokens and fonts
- files: `src/app/globals.css`, `src/app/[locale]/layout.tsx`, `src/components/ui/button.tsx`,
  `src/components/ui/input.tsx`, `src/components/ui/textarea.tsx`
- action:
  - Load Zilla Slab (500/600/700), Nunito Sans (variable) and Caveat (variable) via
    `next/font/google` with CSS variables on `<html>`; `--font-sans` uses Nunito Sans, new
    `--font-display` (Zilla Slab) and `--font-hand` (Caveat) theme fonts.
  - Replace the neutral light tokens with the sketch palette (kraft background `#c8a679`,
    paper cards `#fbf4e4`, terracotta primary `#b5532f`, olive, cream accent), `--radius: .5rem`,
    plus index-card rule tokens; add a dark espresso set under `prefers-color-scheme: dark`.
  - Base layer: paper-fibre texture on `body`, display font on `h1`/`h2`, `overflow-x: clip`.
  - Component classes: `paper-label` (zigzag bottom edge), `index-card`, `recipe-sheet`
    (red margin line + tape), `recipe-steps` (terracotta numbered circles), `polaroid`.
  - Inputs/textarea get a paper background instead of transparent; outline buttons get a
    translucent paper fill so they read on kraft.
- verify: `npx tsc --noEmit`; `npx eslint` on changed files.
- done: tokens, fonts and component classes exist; nothing renders with the neutral palette.
