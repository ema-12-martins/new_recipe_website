# Quick 261023-m2i: A visible warning when a recipe is incomplete

User (pt): "agora não deixa criar mas devia ter um aviso a dizer não pode criar uma receita sem...".
Cause: the field messages render beside each field near the top of the form; the member taps Save at
the bottom and sees nothing happen. With photos, the files were uploaded before the server refused.

## Task 1: Shared check + server state

- `missingParts(values)` in `src/lib/recipes/missing.ts` (no zod, safe for the browser).
- Server `validate` uses it: missing parts get `titleRequired` / `ingredientsRequired` /
  `stepsRequired`; the state carries `missing`.

## Task 2: Form warning

- `handleSubmit` checks first; if parts are missing it stops the submit (no photo upload) and shows
  the field messages plus an alert right above Save: "Não é possível guardar uma receita sem título,
  ingredientes e passos." with one bullet per missing part.
- New messages: `titleRequired`, `incomplete` (pt/en).

## Verify

- typecheck, eslint, `vitest run tests/unit` (new `recipe-missing.test.ts`).
- E2E "a recipe without ingredients or steps is not saved" via `_pw-isolated.config.ts` (no DB reset;
  the test saves nothing) on desktop and phone.
