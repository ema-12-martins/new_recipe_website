# Quick 261023-l4j: read recipe photos with Groq vision

## Objective
Tesseract failed on the owner's real handwritten photos. In an exploration spike the owner's
free, card-less Groq key read all four real photos well (`qwen/qwen3.8-27b`, JSON mode, under
1 s each). Make it the reader behind "Ler receita".

## Facts from the spike (2026-10-23)
- Model `qwen/qwen3.8-27b` accepts base64 images and JSON mode (console.groq.com/docs/vision).
- Free limits for that model: 30 requests/min, 1000/day; input tokens per minute 7000 (429
  message); each page costs about 1.8-1.9 K input tokens regardless of size (768-1600 px).
- Groq does not retain inference data by default; reliability/abuse logs (up to 30 days) can be
  turned off in Data Controls (console.groq.com/docs/your-data). Training on API inputs and the
  processing region could not be confirmed (unresolved).

## Tasks
1. **Provider** `src/lib/recognition/groq.ts` (server-only): sends pages in chunks of up to 3
   (one request each, pages in order) with the spike prompt, JSON mode and hidden reasoning;
   validates the JSON shape; merges chunks (first non-empty title, ingredients and steps
   appended); on 429 waits `retry-after` (header or "try again in Xs") once per chunk if it fits
   before the abort; any other error throws. Confidence is null.
2. **Selection** `config.ts`: `RECOGNITION_PROVIDER` unset → `groq` when `GROQ_API_KEY` is set,
   otherwise `tesseract`; explicit values `groq`, `tesseract`, `stub`, other = off.
   Server deadline 110 s, client 120 s, `maxDuration` 120 (multi-chunk reads wait for the
   per-minute limit). Reading hint copy updated.
3. **Safety and docs:** `GROQ_API_KEY` server-only (.env.example), `check:secrets` scans for
   `gsk_` keys; 02-PROVIDER-DECISION.md records the switch and the unresolved items.
4. **Tests:** unit tests for the provider (request shape, chunking/merge, 429 retry, bad JSON)
   and the selection; local production run of the real UI with the owner's key and the four
   photos; isolated e2e for the draft flow (stub).
