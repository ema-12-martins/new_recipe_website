## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet -> /{locale}/join/{token} | anyone holding a link; untrusted token, email, password |
| owner browser -> members actions | owner-only operations |
| Next.js server -> Supabase admin API | service role used for account creation and redeem |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-20 | Spoofing | invite token guessing | high | mitigate | 256-bit random token (randomBytes(32)); only SHA-256 hash stored; lookup by hash; no listing endpoint for non-owners |
| T-01-21 | Tampering | double or concurrent redemption | high | mitigate | redeem_invite single conditional UPDATE ... RETURNING inside one function; loser's auth user deleted; concurrency integration test |
| T-01-22 | Elevation of Privilege | non-owner creating/listing/revoking invites | high | mitigate | invites RLS select/insert require is_owner(); revoke_invite checks is_owner(); redeem_invite executable by service_role only; integration tests for member and non-member |
| T-01-23 | Information Disclosure | token leakage via Referer or storage | medium | mitigate | global Referrer-Policy no-referrer; plain token returned only in action state, never persisted or logged; 7-day expiry; revocation |
| T-01-24 | Denial of Service | orphaned auth users from failed joins | low | mitigate | pre-check invite before createUser; compensating deleteUser on redeem failure |
| T-01-25 | Spoofing | joining while signed in as a different account | low | mitigate | join page requires sign-out first |
| T-01-SC | Tampering | npm installs | high | mitigate | this plan installs no packages; any new install requires a blocking package-legitimacy checkpoint first |
</threat_model>
