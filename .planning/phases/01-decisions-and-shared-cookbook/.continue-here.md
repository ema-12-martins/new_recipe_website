## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| New e2e browser contexts inherit the owner session | `browser.newContext()` picks up the project's owner `storageState`, so a "device" opens already signed in as the owner | advisory | Pass `storageState: { cookies: [], origins: [] }` (see `openDevice` in tests/e2e/invites.spec.ts and tests/e2e/member-removal.spec.ts) |
| Signing out in e2e with the owner's shared session | `signOut` revokes the session that every viewport project reuses from tests/e2e/.auth/owner.json | advisory | Exercise sign-out only with a separate member on a new context, never the owner `page`; test helpers sign out with `{ scope: "local" }` |
| `getByRole("alert")` is ambiguous | The Next.js route announcer is an empty `role="alert"` element on every page | advisory | Match alerts by text: `getByRole("alert").filter({ hasText })` |
| PowerShell wildcard paths | `[locale]` / `[token]` / `[userId]` are wildcards: New-Item/Get-ChildItem silently miss, git pathspecs fail; `[[]locale]` plus `(app)` in a git pathspec matched nothing in 01-19 | advisory | Use `-LiteralPath` or `[System.IO.Directory]::CreateDirectory`; in git pathspecs prefer `":(literal)src/app/[locale]/(app)/..."` |
| CRLF source files in scripted mutation checks | Files are CRLF on disk; a PowerShell `.Replace("...`n", "")` silently changed nothing and the "mutated" e2e run falsely passed | advisory | Print `mutated=` ($new -ne $orig) before running the check, match `` `r`n ``, and restore with `[IO.File]::WriteAllText` + `restored=` check |
| PowerShell commit messages | Bash `<<<` here-strings do not exist in PowerShell and abort the whole command | advisory | Build the message in a `@' ... '@` here-string and pipe it: `$msg \| git commit -q -F -` |
| Impure calls during render | eslint `react-hooks/purity` rejects `Date.now()` in a component body | advisory | Compute time-dependent values in a data loader outside render (see `loadMembersData` in members/page.tsx) |
| Typing into controlled forms before hydration | WebKit typed before React hydrated and lost the text | advisory | New client forms wrap fields in `<fieldset disabled={!hydrated}>` (useSyncExternalStore) |
| Form actions reset uncontrolled inputs | React resets uncontrolled fields after a form action, so choices vanish when the action returns an error | advisory | Keep choices that must survive a failed attempt in controlled state (see `MemberRemovalForm`) |
| Trusting gsd-tools STATE body mutations | `state.advance-plan`/`state.update-progress` cannot parse this STATE.md body; `state.begin-phase` zeroes `progress.percent` | advisory | Skip begin-phase; after each plan update STATE.md frontmatter (`completed_plans`, `percent`) and Current Position by hand. `roadmap.update-plan-progress` (run it AFTER the SUMMARY exists; it counts files on disk) and `requirements.ready-ids` / `requirements.mark-complete` work |
| Tracer then TDD task | When the tracer task already implements the behaviour, the TDD task's tests pass immediately and no honest RED commit exists | advisory | Say so in the SUMMARY and mutation-check the tests (temporarily break the code, confirm the matching test fails, restore with an empty diff) |
| Dropping the page-level membership guard | Soft navigations do not re-render the (app) layout, so a page without `requireMembership(locale)` renders for a removed member | advisory | `tests/unit/app-pages-guard.test.ts` fails if any (app) page.tsx lacks it; 01-14 edits recipes/[id]/page.tsx — keep the call at the top |
