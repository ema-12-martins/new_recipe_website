## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Synthetic pages approving a provider | The made-up benchmark pages are printed handwriting-style fonts, so every OCR service scores well on them | blocking | 02-PROVIDER-DECISION.md may only record "setup verified, handwriting not tested" from synthetic runs; approving a provider needs real handwritten pages run through the same harness (roadmap Phase 2 decision gate) |
| Members reading or deleting the photo bucket directly | Direct bucket SELECT was dropped (migration 20261023120100) after a removed member could keep downloading for 8+ s; member deletes through Storage now silently do nothing | blocking | Read files only through `/api/recipes/[recipeId]/photos/[photoId]` and delete them on the server with `createAdminClient()` after the RLS-checked row step (see `src/lib/photos/apply-changes.ts`) |
| `shadcn add` adding stray packages | `npx shadcn add` tried to add the npm package `cn` and generated imports from it | advisory | After any `shadcn add`, run `git diff -- package.json package-lock.json`; revert and import `cn` from `@/lib/utils` |
| `check:secrets` and the bare `sb_secret_` prefix | supabase-js bundled for the browser contains the literal prefix | advisory | The check now matches `sb_secret_` followed by key characters; do not revert to a plain substring |
| WebKit and ref-mirrored state | A ref copied from props in an effect lost photos when several were added in WebKit | advisory | Use functional `setState` updates for lists that change across awaits (see `PhotoPicker.addFiles`) |
| Supabase Auth sign-in rate limit in tests | Signing in per helper call hit "Request rate limit reached" | advisory | Sign each test user in once in `beforeAll` and reuse the client |
| Offline DB version in tests | IndexedDB is now version 2; opening it with version 1 fails | advisory | Open `cookbook-offline` without a version in tests; keep `constants.ts`, `public/offline.js` and `public/sw.js` aligned (unit test enforces) |
| Running e2e wipes DEV | The Playwright setup project resets the DEV database, which also backs the live demo | advisory | Warn the user before full e2e runs |
