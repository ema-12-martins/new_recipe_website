## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-20 | Tampering | provider SDK supply chain | high | mitigate | install only the approved SDK after explicit user go-ahead; package.json diff gate |
| T-02-21 | Information Disclosure | photos sent to an unapproved or non-EU provider | high | mitigate | provider chosen only from 02-PROVIDER-DECISION.md; EU region configured and checked in the provider console; stub is the default in tests |
| T-02-22 | Information Disclosure | provider credentials in the bundle or repo | high | mitigate | server-only environment variables, no NEXT_PUBLIC_ prefix, .env.example names only, check:secrets must pass |

| T-02-24 | Denial of Service | oversized or repeated recognition requests | medium | mitigate | Content-Length and per-file size checks, 6-photo cap, 55 s abort, maxDuration; client sends only on button press |
| T-02-25 | Tampering | model output stored as confirmed data | high | mitigate | endpoint is write-free (grep gate), draft validated with recipe limits, saving only through the explicit Save action; e2e asserts zero rows after reading |
| T-02-26 | Tampering | injection through recognised text | medium | mitigate | text rendered only as React text nodes and stored via the existing zod schema; no dangerouslySetInnerHTML |
| T-02-27 | Information Disclosure | photos retained at the provider | high | mitigate | retention and no-training terms verified in the benchmark decision (D-17); photos are sent per request and never stored by the endpoint |
